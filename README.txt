SETUP
1. Open app.js.
2. Replace:
   PASTE_YOUR_SUPABASE_URL_HERE
   PASTE_YOUR_PUBLISHABLE_KEY_HERE
3. Supabase:
   Authentication → Sign In / Providers → Anonymous Sign-Ins → Enable
4. Upload these files to GitHub:
   index.html
   style.css
   app.js
5. Connect the GitHub repository to Vercel and deploy.

No additional Supabase tables are required beyond the complete SQL setup already installed.
